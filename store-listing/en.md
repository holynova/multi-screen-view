## Detailed description

Viewport Relay is a multi-viewport testing tool for frontend development and responsive QA.

Enter a URL and choose iPhone SE, iPhone XR, iPhone 16 Pro, iPhone 16 Pro Max, or your own custom sizes. The extension opens each viewport in a separate Chrome window and arranges every window on one display.

Choose one window as the master and let the others follow:

- Synchronize scrolling and navigation
- Match clicks by DOM identity by default
- Switch to relative coordinates for Canvas and visual apps
- Focus, reload, pause, resume, arrange, or close the whole session
- Save custom sizes locally

The extension processes only the data required for synchronization inside the local browser session. It contains no ads, analytics, account system, or remotely executed code.

## Single purpose

Synchronize navigation, scrolling, and clicks across user-selected Chrome windows and manage those windows so responsive layouts can be compared at multiple mobile viewport sizes.
