# Chrome Web Store 上架文案（简体中文）

## 基本信息

- 名称：Viewport Relay
- 简短说明：一个主屏，多个移动端窗口。同步网页导航、滚动与 DOM 点击，快速比较响应式布局。
- 类别：开发者工具
- 语言：简体中文
- 官方主页：https://holynova.github.io/multi-screen-view/
- 支持页面：https://github.com/holynova/multi-screen-view/issues
- 隐私政策：https://holynova.github.io/multi-screen-view/privacy.html

## 详细说明

Viewport Relay 是一个面向前端开发与网页验收的多尺寸测试工具。

输入一个网址，选择 iPhone SE、iPhone XR、iPhone 16 Pro、iPhone 16 Pro Max 或自定义尺寸，扩展会把页面分别打开在独立 Chrome 窗口中，并自动排列在同一块屏幕上。

以一个窗口作为主屏，其余窗口自动跟随：

- 同步滚动位置
- 同步页面导航
- 默认按 DOM 元素特征匹配点击
- 可切换相对坐标点击，适配 Canvas 等页面
- 一键聚焦主屏、刷新、暂停、继续、整理或关闭全部窗口
- 自定义尺寸保存在本机

扩展只在本机浏览器会话内处理同步所需的数据，不包含广告、分析、账号系统或远程执行代码。

## 单一用途

在用户选择的多个 Chrome 窗口之间同步网页导航、滚动和点击，并管理测试窗口，以比较不同移动端视口下的响应式布局。

## 权限说明

- `storage`：在本机保存自定义尺寸、隐私同意状态和当前会话状态。
- `system.display`：读取当前显示器的可用工作区域，以便将全部测试窗口排列到同一屏幕。
- `windows`：创建、排列、聚焦和关闭测试窗口。
- `http://*/*` 与 `https://*/*`：用户可以输入任意 HTTP 或 HTTPS 网站。扩展需要在这些用户选择的页面中读取滚动、点击和 URL，并把操作同步到其他测试窗口。扩展不会在用户未同意并启动会话时处理同步数据，也不会上传页面数据。

- 是否使用远程代码：否
- 处理的数据类型：网页浏览活动、网站内容、用户活动（点击与滚动）
- 使用目的：应用功能
- 数据出售：否
- 用于广告：否
- 用于信用或借贷：否
- 与单一用途无关的使用：否
- 向第三方传输：否
- 显著披露与同意：有，启动页在首次会话前展示并要求主动勾选
