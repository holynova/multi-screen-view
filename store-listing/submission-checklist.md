# Chrome Web Store 提交清单

## 已在仓库中完成

- Manifest V3、1.0.0 版本、描述、主页和 16/32/48/128 图标
- 产品内显著的数据处理披露与主动同意
- 独立隐私政策与支持入口
- 中文和英文商店文案、单一用途、权限理由和隐私表单答案
- 1280x800 截图、128x128 商店图标、440x280 小型推广图、1400x560 Marquee 图
- 明确文件白名单的可重复打包脚本与自动校验

## 开发者账号中仍需本人完成

1. 登录 Chrome Web Store Developer Dashboard，完成开发者注册费、两步验证和联系邮箱验证。
2. 新建商品并上传 `dist/viewport-relay-1.0.0.zip`。
3. 按 `zh-CN.md` 填写商品详情、隐私和分发页。
4. 从 `store-assets/` 上传图标、截图和推广图。
5. 保存草稿，检查警告和预览。
6. 确认发布者信息和分发范围后提交审核。

提交审核会把资料发送给 Google 并可能公开商品，因此应在账号信息确认后由发布者本人执行。
